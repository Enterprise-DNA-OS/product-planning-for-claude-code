# Weekly Review

Run prioritise, release-review and attention, then compliance. Write a Monday review with the priority decisions, release risks and named follow-ups. Never invent a deadline or an approval.

```bash
node scripts/planning.mjs weekly-review
```

Append --json for structured results. Replace example values with the operator's confirmed values. An ambiguous match lists candidates and exits 1. Nothing sends or publishes. Drafts stay in drafts/.
