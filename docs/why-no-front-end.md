# Why the free version has no front end

The working records are releases, features, dependencies, feedback and decisions. A coding agent asks the database questions and runs checked commands. npm run view produces read-only HTML snapshots; npm run docs produces release briefs and decision records with brand.json.

Aha! also provides interactive timelines, whiteboards, an ideas portal, collaboration and integrations. The free base does not supply those screens, live synchronisation, a mobile workflow, offline editing or drag and drop. A local database needs one process at a time. Exported HTML is a snapshot and has no login system of its own.

Enterprise DNA can scope a web front end, feedback intake and connections around the business's process. That is implementation work agreed with the owner, not a feature already shipped here. The free base suits an owner or product lead who runs a weekly review from records and private documents.
